# Paradise On One Page

Create a premium responsive one-page restaurant website for a small specialty coffee shop in Minsk. The target audience is 20–35 year old urban customers. The visual identity should feel warm and premium rather than generic. Prioritize mobile-first design, menu readability, location, opening hours and a strong reservation CTA (do it). Use the restaurant's actual brand colors, public menu information and publicly available photos. Do not invent awards, reviews, prices or business facts. Site need to be fully made. Весь текст на сайте должен быть на русском языке. Инстаграмм кофейни: paradise.minskl название Paradise. Проанализируй инстаграмм, информацию в интернете, их основы это блины-фетучини и авторские напитки, так же есть очень красивое место, есть также спуск поближе к воде, желательно чтобы были картинки, важно написать меню с ценами, в иделае эффектные анимации и картинки блюд картинки есть в инстаграмм аккаунте.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
